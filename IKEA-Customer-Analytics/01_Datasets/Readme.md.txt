# Dataset Documentation

## Dataset Source

This project uses the Online Retail II dataset from the UCI Machine Learning Repository.

**Source:** [UCI Online Retail II Dataset](https://archive.ics.uci.edu/dataset/502/online+retail+ii)

## Dataset Overview

- Transaction-level retail data
- Period: December 2009 to December 2011
- Contains invoice, product, quantity, price, customer ID, and country information
- Used for customer analytics, RFM segmentation, and churn analysis

## Dataset Files

The following files were used in this project and are maintained locally due to GitHub file-size restrictions.

| File | Purpose |
|---|---|
| Online Retail II Page 1 | Original transaction data |
| Online Retail II Page 2 | Original transaction data |
| RetailCleaned | Cleaned transaction dataset |
| EcommerceDashboardData | Dataset used for dashboard analysis |

## Data Processing

Data preparation and analysis were performed using SQL Server, Python, and Excel.

The processed data supports customer-level RFM calculations and Power BI dashboard reporting.
